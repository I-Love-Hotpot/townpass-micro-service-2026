# 精簡白話摘要

摘要以「讀完後知道誰要做什麼」為主，不再固定輸出五個分類。預設只呈現「先看重點」及有內容的「別漏掉」，移除重複文句、背景套話與空白的「未提及」欄位；疑點用「待核對」明確標示。完整原文仍保留在結果下方的展開區。

共同摘要規則：`frontend/src/assets/govclear/summary-policy.txt`。Python CLI 直接讀取同一個檔案；Vue 將其透過受限 Native Bridge 交給本機模型，不在 Flutter 另外維護一份舊提示詞。

超過 300 字的文件會多跑一次原文核對：將完整原文與候選短摘要交給同一個地端模型，使用 `summary-review-policy.txt` 補回必要的辦理方式、收件判定、豁免前提與例外。核對有額外推論成本，仍是模型草稿，不能當成正式審核或事實保留保證。

顯示原文與摘要的文字數；只有摘要實際較短時才顯示減少百分比。字數去除空白及 Markdown 排版標記，包含可見段落標題，不等同科學量測的閱讀時間或理解難度。

複製摘要只複製實際顯示的段落，空白的確認欄位不會被複製。原文摘要版本與人工校正流程維持一致：修改來源會清除舊摘要，重新產生後仍可回查當次使用的原文。

合成長文範例在 `local-inference/examples/verbose-notice.txt`，可在 `local-inference` 目錄執行 `python3 govclear.py text examples/verbose-notice.txt` 測試。

## 本機模型實測（2026-11-07）

使用同一個 Gemma 4 E4B Q4_K_M 與合成文件，Python CLI 的新舊摘要規則比較：

| 樣本 | 原文 | 舊摘要 | 新摘要 |
|---|---:|---:|---:|
| 短通知 | 129 | 157 | 106 |
| 兩頁合成文件 | 207 | 216 | 137 |
| 冗長補件通知 | 563 | 441 | 223 |

長文的新摘要包含原文核對輪次。另測試資訊公告不應憑空要求申請或繳費，以及缺少送達日期／地點時標示待核對，並保留「隔天起算」等期限條件。短文與疑點較多的文件可能無法大幅壓縮；不以強制截斷換取縮短。

原始合成測試輸出在 `local-inference/.runtime/results/summary-comparison.json`（已忽略 Git）。字數比較不代表所有公文都能等比例縮短，也不是無遺漏或無幻覺的保證。

完整 TownPass 模擬器整合測試通過（約 123 秒），涵蓋短通知的年份與適用對象、長文核對後的材料／郵寄收件／電話延期／確認豁免，以及多圖校正後的金額與水壺事項。這是整組測試的總時間，不是每份文件的摘要耗時。另有 9 項前端回歸測試、10 項 Python 測試及 Flutter 靜態檢查通過。

## 推論加速（2026-11-07）

Python CLI 和 Flutter 模擬器連線的 `/api/chat` 請求均明確設定
`think: false`，避免逐字辨識及白話改寫額外產生隱藏思考文字。
原本的白話規則、超過 300 字的第二輪原文核對、完整輸出檢查均保留。
`keep_alive: "30m"` 讓使用者校對文字或選下一張圖片時模型維持載入；
最後一次請求後會占用模型記憶體約 30 分鐘，到期由 Ollama 卸載。
參數定義見 [Ollama API 文件](https://github.com/ollama/ollama/blob/main/docs/api.md)。

本機 Apple M5、24 GB、`gemma4:e4b-it-q4_K_M`，使用合成 `notice.png/txt`，
同一模型和提示詞，各設定各一次，模型已載入，不包含 App 啟動時間：

| 工作 | 原設定 | 加速設定 |
| --- | ---: | ---: |
| 單張圖片逐字辨識 | 10.38 秒 | 3.11 秒 |
| 短文字白話摘要 | 21.98 秒 | 3.11 秒 |

此為小樣本測量，不代表所有文件耗時；圖片文字量、冷啟動和長文二次核對仍影響等待。
範例辨識文字在兩種設定下相同，摘要日期、費用、資格與例外均保留。
量測紀錄在本機 `.runtime/results/speed-comparison.json`（不納入版本控制）。
Flutter 設定變動需要重新執行 App，只有重新整理 Vue 頁面不會更新原生連線程式。

加速版驗證：Python 11 項測試、Flutter 靜態分析與 2 項來源限制測試通過；
完整 iOS 模擬器流程（短文、長文必要條件核對、多圖排序／辨識／人工更正／合併摘要／返回服務頁）通過，
測試執行約 29 秒，不含 Xcode 建置及啟動。
