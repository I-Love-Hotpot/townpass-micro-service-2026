# 選圖後自動摘要

保留版分支：`snapshot/govclear-reviewed-fast`。
新版分支：`feat/govclear-auto-image-summary`。
微服務與 TownPass 各有同名分支；快照分別為 `11e64bf`、`4faead2`。

在「圖片摘要」選擇一張或多張照片，或按「載入範例」，即自動逐張辨識，
全部成功後合併產生白話摘要。不需按開始辨識，也不需先確認辨識文字。
進度涵蓋辨識與摘要，顯示的耗時是整次流程。

辨識文字收在「查看或修正辨識文字（選用）」中，摘要依據也可在結果展開。
重新排序、移除圖片或手動修正會清除舊摘要；按「重新產生摘要」套用修改。
加入照片會自動處理新加入的頁面，保留既有已完成／人工修正的文字，再合併摘要。

任一頁失敗或沒有文字時，不產生不完整文件的摘要；保留成功頁面供重試。
停止處理後不會接續摘要，延遲回傳的舊結果會被忽略。
合併文字超過 6,000 字時提示分批處理，不自動截斷。
文字摘要模式仍由使用者貼上文字並按按鈕；Python CLI 與推論模型不變。

本分支只保存在本機，沒有推送遠端。
